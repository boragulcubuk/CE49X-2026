3 Background: NASA FIRMS
NASA's Fire Information for Resource Management System (FIRMS) provides near
real-time active re and thermal anomaly data derived from satellite observations. The system
uses thermal anomaly detection algorithms applied to data from two instrument families:
 MODIS (Moderate Resolution Imaging Spectroradiometer)  aboard the Terra and Aqua
satellites, providing data at ∼1 km resolution since 2000.
 VIIRS (Visible Infrared Imaging Radiometer Suite)  aboard the Suomi NPP and
NOAA-20 satellites, providing data at ∼375 m resolution since 2012.
Each detection record includes geographic coordinates, acquisition date and time, condence
level, brightness temperature, and Fire Radiative Power (FRP) a measure of the ther-
mal energy output in megawatts. Importantly, FIRMS detects any thermal anomaly, not just
wildresthis includes industrial res, oil facility burns, explosions, and other high-temperature
events.
3.1 Accessing the Data
1. Register for a free MAP_KEY at: https://firms.modaps.eosdis.nasa.gov/api/area/
2. Use the area endpoint (bounding box) or the country endpoint (ISO3 country codes)
to download data.
3. The API returns up to 5 days per request . For historical data, append a date parameter
( YYYY-MM-DD ). To collect longer periods, loop through 5-day chunks.
4. Use _SP (Standard Processing) sources for historical data and _NRT for near real-time.
Full API documentation: https://firms.modaps.eosdis.nasa.gov/api/area/
